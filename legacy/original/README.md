# Original repository snapshot

These Python sources and chart images are copied byte-for-byte from commit `4818069c5c22f085aab08d127326a578a79e55d5`. `manifest.json` records source commit, path, and SHA-256 for every copied file.

The original charts are retained as historical context. They reflect the original train/validation/test splits and target choices, so comparisons in the revived research use new chronological forecasts and label original plots as historical diagnostics.

The bulky original CSVs are not copied here. The repository has a separate local-only recovery command for the processed subset; the full raw Kaggle data is available from [Tweets about the Top Companies from 2015 to 2020](https://www.kaggle.com/datasets/omermetinn/tweets-about-the-top-companies-from-2015-to-2020), subject to Kaggle's current access and dataset terms.
